## GPT 위임 프롬프트

```
[네이버 블로그 애드포스트 신청용 포스트 작성 지시]

목적: 네이버 애드포스트 승인 통과
채널 정체성: "일본 생활 제도 가이드" — 행정·세금·비자·노동복지 실용 정보
타겟: 일본 거주 중이거나 준비 중인 한국인

형식 조건:
- 분량: 포스트당 1,200~1,500자
- 구조: 소제목 3~4개 + 본문 + 마무리 요약
- 표/체크리스트/준비서류 목록 반드시 포함 (정보 밀도 확보)
- 이미지: 포스트당 1~2장 (저작권 무료)
- 복사 금지: 타 사이트 문장 그대로 사용 금지
- 키워드: 제목 앞쪽 배치, 본문 5~10회 자연스럽게 반복

문체/신뢰도 조건:
- 실제 후기처럼 꾸미지 말고 정보 정리형 문체로 통일
- 단정형 표현 피하기 — "경우에 따라 다를 수 있습니다" 명시
- 공식 기관명 본문에 자연스럽게 포함
  (출입국재류관리청, 일본연금기구, 세무서, 지자체 등)
- 본문 말미에 "제도는 변경될 수 있으므로 최신 정보를 확인하세요" 1~2문장 추가

발행 전략:
- 하루 1~2개, 2주 내 10개 완료 목표
- 각 포스트는 독립된 주제, 내용 중복 없이 작성

작성 키워드 목록:
1. 일본 취업비자 신청 절차 — 한국인이 회사 내정 후 준비할 것들
2. 일본 건강보험 가입 방법 — 국민건강보험과 회사 사회보험 차이

4. 일본 확정신고, 직장인도 해야 할까 — 해야 하는 경우 총정리
5. 한국 운전면허를 일본 면허로 바꾸는 방법 — 외면절차 준비 서류
```
